## Overview

Represent immutable release distribution and migration paths; this is not a product UI.

## Colors

Use the shared warm-black/champagne family identity with semantic success, warning and critical states.

## Typography

Use system prose and monospace for formulae, casks, commands, versions and checksums.

## Composition

Show upstream tag → immutable asset → checksum → formula/cask → install/test as a legible sequence.

## Components

Use package rows, migration notices, verification receipts and rollback cards.

## Accessibility

Keep commands copyable as text, preserve contrast/focus and reflow at mobile widths.

## Release assets

Visuals may announce existing upstream releases only after exact public readback.

## Anti-patterns

Never imply the tap builds binaries, never publish before upstream, never invent checksums, and never hide disabled compatibility stubs.
